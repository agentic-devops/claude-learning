#### 2\. System Setup & Environment Configuration

##### Technical Setup Guide

* **Download the Claude Desktop App:**  Avoid the browser-based interface. The desktop application provides superior stability and system-level integration required for complex Model Context Protocol (MCP) workflows and global keyboard shortcuts.  
* **Enable Artifacts:**  Toggle "Artifacts" in settings to enable a dedicated sidecar window for real-time visualization of code, technical diagrams, and system architectures.  
* **Configure Custom Instructions (The AIM Protocol):**  Do not use generic instructions. Use the  **AIM Protocol**  to define a persistent persona:  
* **Act:**  Define the specific expert role (e.g., "Act as a Senior Information Architect").  
* **Input:**  Describe the nature of the data you will provide.  
* **Mission:**  State the overarching objective for all interactions.  
* **Connect Real-World Data (Alpaca Integration):**  For automated market analysis, integrate the Alpaca Brokerage API. Generate your API keys and configure them within your environment.  **Critical Safety Buffer:**  Always start with  **Paper Trading**  (simulated execution) to verify logic before deploying live capital.

#### 3\. Organizational Strategy: Building Your AI Operating System

##### The ESPE Framework

The ESPE process is the raw input used to construct your "AI Operating System Template," moving your workflow from ephemeral chats to a persistent environment.

* **Extract:**  Identify your core heuristics, technical style guides, and repeating constraints.  
* **Synthesize:**  Combine these into a cohesive logic set.  
* **Operating System:**  Inject this synthesis into Claude’s Custom Instructions or Project context to create a persistent environment that understands your stack.

##### Claude Projects: Contextual Grounding

Projects allow you to "ground" the model in reality, preventing the probabilistic hallucinations of a "drunk genius." To ground a project, upload:

* Standard Operating Procedures (SOPs) and technical "Specs."  
* API references and existing system architectures.  
* Prior work (code repos, technical documentation) to establish tone and logic patterns.

##### MCP & Connectors: Plugging Into Insider Data

* **Capitol Trades:**  Plugs Claude into politician trading data (Smart Money). Use this to track high-performers like Michael McCaul, whose trades frequently outperform the S\&P 500\.  
* **Higgsfield:**  A connector that allows Claude to generate high-fidelity video ads and content directly from the chat interface.

#### 5\. Prompting Architecture: From Zero-Shot to Agentic Reasoning

##### The Intelligent Hill

Prompting is not a "ask and receive" transaction; it is an architectural climb.

1. **One-Shot:**  Provide a single clear example to define the output structure.  
2. **Few-Shot:**  Provide 3+ examples (Grounding) to establish patterns.  **Pro Tip:**  Ask the AI to explain the pattern back to you before execution to ensure alignment.  
3. **Chain of Thought (CoT):**  Force the model to "think step-by-step" and show its work. This trigger phrase is the most vital line in any complex prompt to reduce hallucinations.  
4. **Agents:**  Use agentic prompts that combine Researcher, Analyst, and Draftsman roles into a single execution loop.

##### The PRIME Framework

Architect every major mission using the PRIME structure:

* **Purpose:**  Define the role and the high-stakes objective.  
* **Research:**  Provide the grounding context, links, and data.  
* **Interview:**  Instruct the AI to ask you 3-5 clarifying questions or identify patterns before it begins the task.  
* **Mechanics:**  Set strict constraints, tone, and the "Think step-by-step" requirement.  
* **Examples:**  Provide gold-standard references for the desired final output.**Warning:**  Claude is a "Drunk Genius." It is brilliant but prone to wandering. As the architect, you must always be the one driving the car.

#### 6\. The Karpathy Method: 10x Engineering

Andrej Karpathy (former Head of AI at Tesla) advocates for a shift from "Vibe Coding"—guessing at prompts—to "Agentic Engineering."

1. **Layer 1 (The Spec):**  Never prompt code directly. First, architect a "Spec" document in plain language defining the requirements, logic flows, and edge cases. This is your grounding context.  
2. **Layer 2 (The Prompt):**  Use the Spec as the foundation for Claude Code or Claude Cowork to generate the implementation.  
3. **Layer 3 (The Agentic Loop):**  Grant the AI permission to run tests, find errors, and iterate against the Layer 1 Spec until the output is verified.
